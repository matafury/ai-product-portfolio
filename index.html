01
主导 · 企业内部

现场工程师知识 RAG 助手

把分散在各处的产品资料，做成一个「问一句就给准确答案、还能溯源到原文」的内部知识助手。

10 分钟 → 2 分钟单次资料检索平均耗时
+80%检索效率提升
83%回答准确率

我做了什么

  • 拆解真实痛点：资料分散、检索慢、遇到问题依赖跨人求助；把公司资料按「问题解决库 / 使用手册库 / 杂项库」分类，并定义版本回答规则。
  • 规划核心能力链路：文档上传与解析 → 知识切片 → 语义检索 → 答案生成 → 原文溯源。
  • 用版本识别 + 分类检索，提升答案与具体产品版本、问题场景的匹配度。

工具栈Dify · bge-m3 · RAG 评测 · Prompt Engineering

02
个人项目 · 开源

多平台 AIGC 内容自动化控制台

自己从 0 搭的一套系统：把「内容生成 → 多平台发布 → 发布状态与数据监控」串成一条能真跑起来的流水线。引擎开源在 GitHub。

5 平台统一管理与投递
端到端跑通生成到发布全链路
开源Apache 2.0，引擎公开

我做了什么

  • 用 Dify 编排 DeepSeek 文案 + 本地出图（ComfyUI / FLUX），生成竖屏图文与视频内容。
  • 做多平台（抖音 / 小红书 / 快手 / 视频号 / X）的账号管理、作品监控、一键发布与投递后核实。
  • 定义投递幂等规则，解决「空发 / 重复投递」等真实工程问题，保证发布结果可核实。

工具栈Dify · DeepSeek · Playwright · FastAPI · Node.js · Python

03
个人项目

图书解说 / 预告片视频管线

输入书名和作者，自动产出一条竖屏图书视频：选题研究 → 分镜 → 出图 → 配音 → 字幕 → 合成，全程可复现。

多部成片《蛤蟆先生》《平凡的世界》《百年孤独》等
可发布水准达实际投递质量
测评集驱动质量可量化迭代

我做了什么

  • 用 DeepSeek 做选题研究与文案结构，固化成可复用的生成管线。
  • 本地 FLUX 出图、语音克隆配音、ASS 字幕烧录、ffmpeg 竖屏合成。
  • 为配音文案建了测评集，用结构/温度量化打分来控制质量，而不是凭手感。

工具栈DeepSeek · HyperFrames/Remotion · FLUX · 语音克隆 · ffmpeg

个人项目 · 产品演示

工业产品 AI 演示片：扫描球防撞

给一个硬件产品的专利卖点做 5 秒 AI 演示：真机抠像 → AI 生成工业场景 → 本地图生视频 → 合成带字幕的演示片。

1080p · 5s对外演示成片
零外采全本地 / 开源工具
首帧到成片完整合成链路

我做了什么

  • 把真机抠成透明素材，用 AI 生成工业场景与挡板，合成悬浮首帧。
  • 本地图生视频：扫描球滑向挡板减速、触发探测波纹。
  • 定格补足时长、烧录中文分镜字幕，输出对外可用的演示片。

工具栈图生视频（本地）· 抠像合成 · ffmpeg
